## 🛠️ Requirements

```bash
# ติดตั้ง Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# เวอร์ชันที่ใช้
rustc 1.75+
cargo 1.75+

# Tools เพิ่มเติม
cargo install cargo-watch
cargo install sqlx-cli
cargo install cargo-nextest
```
